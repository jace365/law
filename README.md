# ⚖️ 법과사회 내신 대비 (Law_and_Society)

고등학교 2학년 **법과사회** 내신 대비용 웹앱입니다. 서버 없이 정적 파일만으로 동작하고, 휴대폰 홈 화면에 앱처럼 설치(PWA)할 수 있습니다.

| 메뉴 | 내용 |
|---|---|
| 🏛 홈 | 학습 현황(푼 문제·정답률·오답 수·모의고사 최고점), 오늘의 한 줄 빈칸 |
| 📖 이론 | 5개 단원 핵심 정리 표. **핵심어 가리기** 모드로 백지 복습 |
| ✏️ 빈칸 | 학습지 빈칸 96개. 밑줄을 눌러 확인, “몰라요”를 누르면 오답노트에 저장 |
| ❓ 문제 | 단원별 100문항, 누르는 즉시 채점과 해설. 틀리면 오답노트 자동 저장 |
| 📝 시험 → 🎯 실전시험 | 시작할 때마다 **랜덤 20문항**(단원별 4문항). 회차별 점수표, 점수 추이 그래프, 현재 수준, 약점 단원, 지난 답안 다시 보기·삭제 |
| 📝 시험 → 모의고사 | 고정 5회 × 20문항(문항당 5점). 타이머, OMR 표, 단원별 정답률 |
| 📕 오답노트 | 문제·빈칸 오답 모아 보기, 정답·해설 펼치기, 오답만 다시 풀기, 개별·전체 해제 |

틀린 문제는 자동으로 오답노트에 담기고, 모든 문제 카드에 **＋ 오답노트 담기 / ✔ 오답노트 해제** 버튼이 있어 어디서든 직접 담거나 뺄 수 있습니다. 기록은 브라우저(localStorage)에만 저장됩니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 **그대로 루트에** 올립니다 (`index.html`이 맨 위에 있어야 함).
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속됩니다.

명령줄로 올릴 때:

```bash
git init
git add .
git commit -m "법과사회 내신 대비 앱"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소이름>.git
git push -u origin main
```

## 휴대폰에 앱으로 설치

홈 화면 아래 **📲 휴대폰에 앱으로 설치하기** 카드에서 바로 설치할 수 있습니다(안드로이드는 `앱 설치` 버튼, 아이폰은 안내 문구). 글꼴은 모바일 앱에서 많이 쓰는 Pretendard를 쓰고, 불러오지 못하면 휴대폰 기본 글꼴로 표시됩니다.

- **안드로이드(크롬)**: 배포 주소 접속 → 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**
- **아이폰(사파리)**: 배포 주소 접속 → 공유 버튼 → **홈 화면에 추가**

설치 후에는 인터넷 없이도 열립니다(https 주소에서만 오프라인 저장이 동작). PC에서는 `index.html`을 더블클릭해도 바로 실행됩니다.

## 문제·이론 수정하기

| 파일 | 내용 |
|---|---|
| `data/theory.js` | 단원별 이론(HTML). `<b>`로 감싼 말이 핵심어(가리기 대상) |
| `data/blanks.js` | 빈칸 문장. `{정답}` 형식 |
| `data/q1.js` ~ `q5.js` | 단원별 문제. `[문제, [보기 5개], 정답번호, 해설, 자료(선택), 보기섞기금지(선택)]` |

- 각 단원의 1~4번 문제는 모의고사 1회, 5~8번은 2회 … 17~20번은 5회에 들어갑니다. 21번째부터는 문제풀이 전용입니다.
- 보기 순서는 문제마다 고정된 규칙으로 섞여 정답 번호가 고르게 분포합니다. 계산 결과처럼 순서를 유지해야 하는 문제는 마지막 값을 `1`로 둡니다.
- 데이터 파일을 새로 추가하면 `index.html`의 `<script>`와 `sw.js`의 `FILES`에도 넣고 `CACHE` 버전을 올려 주세요.

※ 형제자매의 유류분은 2024년 헌법재판소 위헌 결정으로 효력을 잃었습니다. 이론에 이 내용을 함께 적어 두었습니다.
